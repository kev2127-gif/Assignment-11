# Assignment-11
The DotStimVisualization code creates a task where the participant is required to use the left and right arrow keys to indicate which direction they believe the array of dots on the screen are moving. There is a welcome page and an instruction page to orient the participant to the experiment prior to showing dots. The dots will appear on the screen after a fixation cross is presented. The dots will vary in coherence and direction once presented. Participants will respond with L and R arrow keys on their keyboard. The response, reaction time, key, and correctness of the response will be recorded into a data frame. The data visualization is set up to show the reaction time across the X axis and the number of correct responses associated with each reaction time.
